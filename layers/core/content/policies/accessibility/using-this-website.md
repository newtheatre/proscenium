title: Using this website
order: 20
revised: 2026-11-18
---

You should be able to:

- reach and use everything with a keyboard alone;
- use the site with a screen reader;
- zoom to 200% without the page breaking or text being cut off;
- read the site in a light or a dark look, with clear contrast in both;
- use the site on a phone, a tablet or a computer;
- fill in forms that say plainly what went wrong and where.

We aim to meet level AA of the Web Content Accessibility Guidelines, version 2.2. That is the recognised standard for accessible websites.
