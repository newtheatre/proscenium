# Changes for marked forms (24 November 2026)

The third round's Festival-ready changes specification (stories FB-513 to FB-515) gives forms
correct answers, points and a pass mark, so that Training's quizzes and any other marked form can
use them. This page records FB-513 as built. Where this page and an earlier part disagree, this page
wins.

## What changed

| # | Change | Replaces or adds to |
| --- | --- | --- |
| 1 | **A question can carry a correct answer.** On a choice (single, several or a dropdown), yes or no, number or short text question: the option ids that are right, true or false, a range from and to (either end may be open), or the accepted texts, compared without regard to case or the spaces round them. Each is worth whole points, 0 to 100, 1 when left out, with optional feedback for right and for wrong (500 characters each) | Part 2, the definition format |
| 2 | **A form can be marked.** `marking` on the definition holds an optional pass mark (whole points) and what the person is shown after sending: the score only, the score and feedback, or the score, feedback and the correct answers | Part 2, the definition format |
| 3 | **Marking happens on the server only (MK1).** Each send is marked in the same unit of work as the response, from the stored answers and the key of the version answered. A response keeps `score`, `out_of` and `passed`; whatever a request says about a score is never read | Part 3, sending a response |
| 4 | **Exact matches only (MK2).** A choice is right only with every correct option and no other; "Other" is never right. There is no part credit | Part 3 |
| 5 | **A hidden question is not marked (MK3).** Its points leave that response's total | Part 3 |
| 6 | **What the person sees follows the form (MK4).** After sending, on the form's own page and on their copy under My forms. The correct answers are shown only where the form says so | Part 5, the form a person answers |
| 7 | **A changed response is marked again (MK5),** when the person changes it where the form allows, or sends it back when it was returned. The stored score is the latest; an earlier revision's is worked out again when it is read | Part 3, changing a response |
| 8 | **The key never leaves the server.** Every route that sends a definition to a browser sends it through `publicDefinition`, which drops the correct answers and the pass mark. Builder routes send them only to somebody who may mark the form (`authorDefinition`); a test reads every route's source and fails on any other way out | Part 4 |
| 9 | **A new ability, `forms.form.mark`,** on a form, implying `forms.form.edit`. It sets correct answers, points and the pass mark. Somebody who may edit but not mark never sees them, and a save of theirs keeps the draft's. On upgrade it is given to every role and fact that already held `forms.form.edit` or `forms.form.publish` | Part 7, abilities |
| 10 | **Staff see how a response was marked:** its score and whether it passed, and each marked question's points beside its answer | Part 5, reading a response |
| 11 | **Hosts may pin a version.** `addResponse` takes an optional `versionId` (a published version of the placement's form, else refused `forms.version-not-of-form`) and returns `marking` when that version has correct answers. `slotFormVersion(placementId, versionId)` reads one version as its person may be sent it | Part 4, services |

## The checks before publishing

| Problem | Level |
| --- | --- |
| A correct answer on a question that cannot be marked, or one that does not suit it (`answer-wrong-type`) | error |
| A correct answer inside a repeating group (`answer-in-group`) | error |
| A correct answer on a special-category question (`answer-special`): marking says whether a sealed answer was right | error |
| An empty correct answer, or a range with neither end (`answer-empty`) | error |
| A correct option the question no longer has (`answer-unknown-option`) | error |
| A range whose lowest is above its highest (`answer-range`) | error |
| Two correct options on a question where only one can be chosen (`answer-never-right`) | error |
| A pass mark above the points there are (`pass-mark-over`) | error |
| Marking on, with no correct answers yet (`marking-no-answers`) | warning |

## In the builder

The End card holds "Mark the answers", the pass mark and what to show after sending; only somebody
who may mark sees them. With marking on, a markable question's details gain a "Correct answer"
section: the answer, its points and the two pieces of feedback.

## Two more templates (FB-515)

| Template | What it holds |
| --- | --- |
| Quiz (`forms.quiz`) | One page of five questions, each with a correct answer and points (six in all), a pass mark of five, and the score and feedback shown after sending. The wording is an example of a front-of-house safety quiz; the theatre makes it its own |
| Crew sign-up (`forms.crew-sign-up`) | T-shirt size, the days a crew meal is wanted, and dietary needs, classed special category so only those allowed can read who asked for what. For a crew call (FH-49), answered once by each volunteer |
