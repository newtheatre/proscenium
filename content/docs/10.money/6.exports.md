Exports is at **Manage, Money, Exports**. Reading the screen needs `finance.read`; downloading
the export needs `finance.export`; changing a nominal code needs `finance.write`. The
Treasurer holds all three. The export is what the Students' Union's own accounting takes in:
one row per ledger line, each categorised against the SU's nominal codes, nothing totalled or
invented on the way out.

## Taking the SU export

![Exports with the from date (1), the to date (2), Export CSV (3) and the nominal code mappings (4)](/images/docs/money/exports.png)

1. Set **from** and **to** (London days; the screen opens on today). **Export CSV** stays
   disabled while the range ends before it starts.
2. Press **Export CSV**. The browser saves a file named `su-export-<from>-to-<to>.csv`.

Each row of the file is one ledger line: its date, its category (the kind of line, such as
"Ticket collection" or "Bar item"), the SU nominal code, the amount in pence and the same amount
in pounds as a plain decimal for a spreadsheet. A refund line is already negative, so summing a
category reaches the net figure the reports show. A line whose kind and source have no nominal
code is still exported, on its own row with the code `UNMAPPED`; nothing is ever dropped.

::callout{icon="i-lucide-info" color="info"}
A range that has not been [closed](/docs/money/periods) exports anyway. The figures may still
move until it is closed, so treat such a file as provisional and take it again after the close.
::

## Setting a nominal code

Every kind of ledger line, paired with the surface it posts from, maps to one SU nominal code.
The pairs are fixed by the system; the treasurer sets only what each maps to.

1. In **Nominal code mappings**, find the pair (the ledger line and its source) and press
   **Edit**. The button shows only with `finance.write`.
2. Type the **SU nominal code**, or clear the field to send this pair's lines out on the
   explicit unmapped line.
3. Press **Save**.

## If something goes wrong

- **"This export would return more than 20,000 rows. Narrow the date range and try again."**:
  the range is too wide for one file. Split it and take two.
- **"The range ends before it starts"**: the to date is earlier than the from date.
- **"No ledger line is ever posted under that kind and source together"**: the pair being saved
  is not one the system posts. Reload the page and edit a row from the table.
- **"Give it a nominal code"**: the code is only spaces. Type one or clear it entirely.
- **"The mappings could not be read."**: the query failed or you no longer hold `finance.read`.
  Reload the page.
- **Export CSV is missing**: you do not hold `finance.export`. General finance reading is not
  enough to take a copy for the SU.

## What happens next

Every export writes `finance.exported` to the audit trail with the range, the row count and
whether the range was closed. Every code change writes `finance.nominal-mapping.changed` with the
old and new values.
