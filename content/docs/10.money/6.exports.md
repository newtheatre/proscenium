Exports is at **Manage, Money, Exports**, and the Treasurer reads it, takes the export and
changes a nominal code. The export is what the Students' Union's own accounting takes in:
one row per ledger line, each categorised against the SU's nominal codes, nothing totalled or
invented on the way out.

## If something goes wrong

- **"This export would return more than 20,000 rows. Narrow the date range and try again."**:
  the period is too wide for one file, and **Export CSV** stays disabled while it shows. Choose a
  season, or a **Custom range**, and take the year in two or more files.
- **"What this export covers could not be read."**: the line under the controls did not come
  back. Reload the page; **Export CSV** still works.
- **"That season does not exist"**: the season was deleted after the page opened. Reload the
  page and choose again.
- **"The range ends before it starts"**: the to date is earlier than the from date.
- **"No ledger line is ever posted under that kind and source together"**: the pair being saved
  is not one anything posts. Reload the page and edit a row from the table.
- **"Give it a nominal code"**: the code is only spaces. Type one or clear it entirely.
- **"The mappings could not be read."**: the list did not come back, or your role no longer
  reads the ledger. Reload the page.
- **Export CSV is missing**: taking a copy for the SU is the Treasurer's, and reading the ledger
  alone is not enough.

## Taking the SU export

![Exports with the period (1), the year (2), Export CSV (3), what the export covers (4) and the nominal code mappings (5)](/images/docs/money/exports.png)

::callout{icon="i-lucide-info" color="warning"}
This picture still shows the from and to dates the screen used to open on. The screen now opens
on **Year**, and the dates show only under **Custom range**.
::

1. Choose the **Period**:
   - **Year** (the screen opens on this one, set to this year): 1 August to 31 July, named by the
     two years it spans, such as 2025/26. This is the SU's yearly return.
   - **Season**: one of the seasons the Box Office Manager has entered on the [Seasons](/docs/box-office/seasons) page, such
     as Autumn or the Fringe, over that season's own days. It is offered only once a season exists.
   - **Custom range**: set **from** and **to** yourself (London days; they open on today).
2. Read the line under the controls: the first and last day the file will cover, how many lines it
   holds, and whether the period is **Closed** or **Open**.
3. Press **Export CSV**. The browser saves a file named `su-export-<from>-to-<to>.csv`.

Each row of the file is one ledger line: its date, its category (the kind of line, such as
"Ticket collection" or "Bar item"), the SU nominal code, the amount in pence and the same amount
in pounds as a plain decimal for a spreadsheet. A refund line is already negative, so summing a
category reaches the net figure the reports show. A line whose kind and source have no nominal
code is still exported, on its own row marked as unmapped, and nothing is ever dropped.

::callout{icon="i-lucide-info" color="info"}
A period that has not been [closed](/docs/money/periods) exports anyway, marked **Open**. The
figures may still move until it is closed, so treat such a file as provisional and take it again
after the close. Once the whole period is **Closed**, nothing more can be posted into it, and
taking the same year or season again gives exactly the same file, as long as no nominal code has
been changed in between. A period closed in two or more pieces, or with any part of it reopened
since, reads as **Open**: close the whole year in one go to have the yearly return read **Closed**.
::

## Setting a nominal code

Every kind of ledger line, paired with the surface it posts from, maps to one SU nominal code.
The pairs are fixed; the Treasurer sets only what each maps to. The same kind of line can post
from more than one surface, and each has its own row: a ticket collected or a walk-up sold at the
bar shows as **Till**, beside the box office's **Desk** row, and the zero-value pass a Fellowship
award issues shows as **System**. Map each of them, or those lines go out unmapped.

1. In **Nominal code mappings**, find the pair (the ledger line and its source) and press
   **Edit**, which shows only to the Treasurer.
2. Type the **SU nominal code**, or clear the field to send this pair's lines out on the
   explicit unmapped line.
3. Press **Save**.

## What happens next

The audit trail reads **SU accounting export downloaded** with whether a year, a season or a custom
range was chosen, the days it covered, how many rows went and whether the period was closed, and **SU nominal code mapping changed** with the old code and the new one.
