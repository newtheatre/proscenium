A pass type is a product: bought once, admitted against a performance of any show it covers. A
season pass, a festival pass, a members' pass. Pass types are managed at **Manage, Box office,
Pass types**. Reading the list needs `ticketing.read` and changing it `ticketing.write`, both held
by the Box office role; dropping a show that live passes already cover needs `ticketing.manage`,
which the Manager role holds.

::callout{icon="i-lucide-info" color="info"}
**A pass is closed, never destroyed, once anything has been issued against it.** A pass type
nothing has ever been issued under can be deleted outright. Extending what a pass covers is
free; dropping a show with a live pass against it needs a manager.
::

## Adding a pass type

![The passes list with the search and filter (1), the Add a pass button (2) and the table (3)](/images/docs/box-office/pass-types.png)

1. **Search** by name, or filter by **Status**, from the toolbar.
2. Press **Add a pass**.
3. Give it a **Name**, a **Web address** (lowercase words joined by hyphens, held once) and,
   optionally, a line on **what it is for**.
4. Set the days it is **Valid from** and **Valid until**: the window in which it admits.
   Optionally set the days **Sales open** and **Sales close**; outside that window the desk
   cannot issue it and a member cannot request it, and an unfulfilled request lapses when sales
   close.
5. Optionally set the **Maximum issued**: the blunt guard against selling more passes than the
   house holds. Empty is uncapped.
6. Add at least one **Price point**, each with its own label and price in pounds; the desk
   offers them all.
7. Choose the shows it **Covers**.
8. Press **Add a pass type**. A new pass type is a **Draft**: nothing can be issued until its status is
   **On sale**.

**Edit** on a row changes everything but the covered shows, which it names read-only and points
at **Covered shows** beside the pass in the list, and adds a **Status** picker: Draft, On sale
or Closed. Closing a pass stops issuing; passes already out keep admitting until they
expire.

## Changing what a pass covers

1. Press **Shows** on the row.
2. Add or remove shows in the picker and press **Save the shows**.

Adding a show takes effect at once for every pass already issued. Removing a show that a live
pass covers is refused unless you hold `ticketing.manage`, because holders bought it on that
promise.

## If something goes wrong

- **"A pass already has the address season-pass"**: addresses are held once.
- **"A pass cannot expire before it starts"** or **"Sales cannot close before they open"**:
  the windows are the wrong way round.
- **"A show is covered once"**: the same show was chosen twice.
- **"Season pass has been issued, so it can only be closed: every pass held against it still
  has to resolve"**: set its status to Closed instead of deleting it.
- **"A manager must remove a show with a live pass against it"**: ask somebody holding the
  Manager role, or leave the show covered.
- **"That show is no longer here."**: the show was deleted while the picker was open. Reload.

## What happens next

A pass type on sale, inside its sales window, appears on the Pass desk screen and can
be requested by a member online. Passes are issued against it at the desk; each admission seats
the holder under the system's own pass-admission ticket type, which counts against capacity like
any other seat. Every change to a pass type, and to what it covers, is in the audit trail.
