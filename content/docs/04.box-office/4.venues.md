A venue is where a performance happens: the auditorium, the studio, a Students' Union space or
somewhere off site. It is its own record, never a flagged room. Venues are managed at **Manage,
Box office, Venues**; reading the list needs `ticketing.read` and changing it `ticketing.write`,
both held by the Box office role.

::callout{icon="i-lucide-info" color="info"}
**A venue is retired, never destroyed.** A venue with a performance, an emergency card or any
other record against it can only be retired: it stops being offered for a new performance and
still serves everything already pointing at it. A venue nothing has ever used can be deleted
outright.
::

## Adding a venue

![The venues list with the search and filter (1), the Add a venue button (2) and the table (3)](/images/docs/box-office/venues.png)

1. **Search** by name, or filter to retired venues, from the toolbar.
2. Press **Add a venue**.
3. Give it a **Name**: what the box office, the rota and every report calls it. Optionally an
   **Address** and a line on **what it is for**.
4. Set the **Capacity** for a general admission house, or leave it empty for an uncapped one.
   A performance can override it.
5. Optionally attach a **Room**. The only effect is that this venue's performances apply
   blackouts to that room, so nobody books it for a rehearsal while a show is on. Nothing else
   about a room is inferred from a venue, or the reverse.
6. Switch on **External venue** for a union or off-site space. It is a reporting flag, not a
   blackout.
7. Press **Add it**.

**Edit** on a row opens the same form. The **Emergency card** button, shown to those who can
read one, opens the show-night emergency cards; the card itself is not edited here.

## Retiring or deleting a venue

- **Retire** stops the venue being offered for a new performance. A performance already in it
  keeps it, and its row still shows it. **Bring back** reverses it.
- **Delete** appears only on a row marked **Nothing yet** in the In use column. It cannot be
  undone.

## If something goes wrong

- **"A venue needs a name"**: the name is required.
- **"A venue is already called Studio"**: names are held once. Distinguish the two.
- **"Studio can only be retired: a performance is scheduled here, it carries an emergency
  card"**: the venue is in use through the records the refusal lists. Retire it instead.
- **"Studio is already retired"** or **"Studio is not retired"**: somebody else changed it
  first; the list has caught up.
- **"Studio changed while you were editing it"**: reload and try again.

## What happens next

A new venue is offered in the performance form at once. Retiring one removes it from that picker
and nowhere else. Every add, change, retirement and deletion is in the audit trail.
