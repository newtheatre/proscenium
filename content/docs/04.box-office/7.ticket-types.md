A ticket type is what a seat is sold as: Standard, Member, Concession. It carries a base price
that a show or a performance can override. Ticket types are managed at **Manage, Box office,
Ticket types**, by the Front of House Manager, who reads the list and changes it.

::callout{icon="i-lucide-info" color="info"}
**A ticket type is retired, never destroyed.** Once anything has been sold under a type, it can
only be archived: an archived type stops appearing for new sales and still resolves for every
ticket, report and export behind it. A type nothing has ever been sold under can be deleted
outright.
::

## If something goes wrong

- **"A ticket type is already called Standard"**: names are held once.
- **"Who may book a members-only type is set when it is added, and not changed afterwards"**:
  a members-only type cannot become open or box office only. Retire it and add another.
- **"A companion ticket is always free"**: a companion type's price is 0 and the field is
  locked to it.
- **"Standard has been sold, so it can only be archived: every ticket sold under it still has
  to resolve"**: archive it instead.
- **"Pass admission is the house's own ticket type: a pass holder is seated under it
  automatically, so it cannot be edited, archived or deleted"**: leave it be.
- **"Standard is already archived"** or **"Standard is not archived"**: somebody else changed
  it first; the list has caught up.

## Adding a ticket type

![The ticket types list with the search and filter (1), the Add a ticket type button (2) and the table (3)](/images/docs/box-office/ticket-types.png)

1. **Search** by name, or filter to archived types, from the toolbar.
2. Press **Add a ticket type**.
3. Give it a **Name**, held once globally, and a **Base price** in pounds, to the penny. A
   show or a performance can override the price later. A figure that is not a price, such as -5
   or 7.555, is refused with the reason rather than changed, and the most a ticket costs is
   £1,000.00.
4. Choose whether it is an **Access or companion** type. An access type is offered only to a
   booker with a verified access profile, and a companion type is the free seat beside them;
   neither ever appears on a public page. This is fixed when the type is created, and the edit
   form names what it was set to rather than leaving it off the form. Until an Access type and a
   Companion type exist, this screen and Access profiles both say so: a verified profile
   entitles its holder to nothing without them.
5. Choose **who may book it**: **Anyone**; **Current members only**, which appears only for a
   signed-in booker whose membership is current, so a guest never sees it; or **Box office
   only**, which the desk and the till sell and no public page ever offers. Use Box office only
   for a comp. Members only is fixed at creation and named read-only on the edit form; Anyone
   and Box office only can be swapped on **Edit** at any time.
6. Leave **Offered on a new performance** on unless the type should be off by default and
   turned on per show or per performance.
7. Press **Add a ticket type**.

**Edit** on a row changes the name, price, description and default, and swaps Anyone and Box
office only; the access kind and a members-only restriction cannot change. The table shows each
type's badges (Access, Companion, Current members only, Box office only, Retired, Off by
default), its base price and whether it has ever been sold.

::callout{icon="i-lucide-triangle-alert" color="warning"}
**A free type open to anyone is a free seat for the public.** Wherever it is on sale, the
public booking page offers it at £0.00. The form warns when a type would be free to anyone, and
so does a show's or a performance's price list when one is on sale there. Make a comp Box
office only.
::

::callout{icon="i-lucide-lightbulb" color="info"}
Pass holders are seated through a ticket type the house keeps for itself. It is not listed
here and cannot be edited, priced or retired.
::

## Retiring or deleting a ticket type

- **Retire** stops the type appearing for new sales. Every ticket already sold under it is
  still priced by it. **Bring back** reverses it.
- **Delete** appears only on a row with a cross in the Sold under column (**Never sold**).
  Deleting also removes the show and performance prices set for it. It cannot be undone.

## What happens next

A new type appears on every show's Ticket types tab and every performance's Prices dialogue to
price or switch off, and is offered on new performances if its default says so. Every add,
change, archive and deletion is in the audit trail.
