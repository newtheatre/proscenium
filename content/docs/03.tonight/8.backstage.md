The backstage board has two ends. **Backstage** at `/tonight/board`, from the hub tile of that
name, is front of house's end: the duty manager's shift opens it, or the Front of house manager
without one. **Join tonight's board** at `/board` is the crew's end, on the wings device or any
phone: no account, no personal data, only tonight's six-digit code and a label. Both ends draw
the same feed and refresh within five seconds.

::callout{icon="i-lucide-key-round" color="warning"}
**The code travels by voice.** It is revealed on the duty manager's screen on request and read
out loud; it is never emailed or notified, and it is hidden again the moment you press **Hide**.
Ten wrong guesses in a row move it on their own.
::

## If something goes wrong

- **"That code was not recognised"**: a wrong or an old code. Ask the duty manager to read it
  again; the join never says which venue you were closest to.
- **"Join the board first"** or **"That device is not recognised"**: this browser holds no
  joined device. Join with the code.
- **"The board was reset: join again with the new code"**: the duty manager reset the board.
  Get the new code by voice.
- **"That preset is not configured, or has been retired"** or **"That milestone is not
  configured, or has been retired"**: the committee changed the set after the button was drawn.
  Reload.
- **"No standing calls yet. Type one below and send it."** or an empty milestone grid: nothing is set up for this
  venue; see [the board's setup](/docs/rota/backstage-board).
- **"Nothing called yet"**: an empty board, not a fault.

## Front of house

![Backstage with the current state (1), the presets (2), the backstage code (3), Reset the board (4) and the free text bar at the foot (5)](/images/docs/show-night/board.png)

1. **Current state** is your last call and the other end's, each with the time it was sent and
   whether the other end has seen it. **Mark seen** beside a call from the wings ticks it for
   them.
2. **Presets** are the committee's one-press messages; press one to send it.
3. **Backstage code**: **Show the code** reveals it in two groups of three, to read over a
   headset; **Hide the code** puts it away.
4. **Reset the board**, at the foot of the page under everything else, disconnects every joined
   device at once and moves the code. The new one does not appear on the confirmation: read it
   out loud.
5. **Free text** sits at the foot of the screen, under the thumb, sent with the arrow: sending is
   what this screen is for, so it is what stays within reach.

Below the current state is **History**, every call from either side with its time, who on the
crew posted it, and a tick once it has been seen.

## The wings

![The join form with the code (1), the label (2) and Join (3)](/images/docs/show-night/board-join.png)

1. **Code**: the six digits the duty manager read out.
2. **Your name or role**: shown to the duty manager beside what you post, nothing else, and not
   checked against anything.
3. **Join**. The device stays joined for the night, or until the board is reset.

Once joined, the crew see the venue's name, the same current state and history, and:

- **Milestones**, the big buttons: the committee's named points of the evening (house open,
  clearance and the like). A milestone is kept for the night report.
- **Presets** and **free text**, as front of house has.
- **Seen** beside a call from front of house this device has not yet acknowledged. A call from
  front of house waits for each device's own tick; another device's tick does not clear it here.

A phone that loses signal keeps working: a press queues, the screen says **… messages waiting to
send**, and they go in order when the connection returns, timed at the moment they were pressed
rather than the moment they finally sent. A message the board genuinely refuses (a preset the
committee retired meanwhile) comes back where it was typed, in the words it was typed in, with the
refusal underneath it and two buttons: **Try again** sends it afresh, **Discard the message**
lets it go. It is never retried on its own, and it never disappears on its own either.

**Mark seen** that does not record says so in a line above the feed, rather than leaving both
ends believing a call was acknowledged. Press it again.

## What happens next

Every join and every message is in the audit trail, with no name attached to a crew message
beyond the label typed at the join. Milestones make the night report's timeline and are kept;
presets and free text are cleared 30 days after the night. A reset notifies every holder of the
duty manager's permission that the board was reset, without naming the new code.
