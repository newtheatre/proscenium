A discount is a percentage off, offered as a button on the till. The list is at **Manage, Bar,
Discounts**, and the Bar Manager opens it and changes it.

::callout{icon="i-lucide-info" color="info"}
**A discount is never free by accident.** Its percentage is capped at
{{ BAR_DISCOUNT_MAX_PERCENT }}%, checked at the moment it is created or edited, so a settings
change takes effect without waiting for a release. Applying a discount keeps its percentage on
the sale line as it stood at the moment of sale, so a later edit or retirement never restates a
charge already made.
::

## If something goes wrong

- **"A discount cannot exceed N%: ... asked for ...%"**: the percentage typed is above the
  configured cap. Ask whoever holds the settings if the cap itself should change.
- **"A discount is already called ..."**: names are unique, ignoring case. Choose another or
  edit the existing one.
- **"... is already active"** or **"... is already retired"**: somebody else changed its status
  first. Reload and try again.

## Adding a discount

1. Press **Add a discount**.
2. Give it a **Name**: what the till button and every report call it.
3. Set **Percent off**, a whole number from 1 to 100.
4. Press **Add a discount**.

![The discounts list with the add button (1) and the edit and retire actions (2)](/images/docs/bar/discounts.png)

1. **Add a discount** opens the form above.
2. **Edit** changes the name or the percentage; **Retire** takes it off the till without touching
   any sale it already discounted, asking first in a dialogue whose button names the discount,
   and **Bring back** restores a retired one.

## Editing and retiring

Editing a discount changes what a future sale does with it; every line already discounted keeps
its own snapshot of the percentage charged at the time, so nothing already rung up is restated.
Retiring stops a discount being offered on the till without deleting it or touching its history;
put it back at any time.
