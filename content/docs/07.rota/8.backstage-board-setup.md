The backstage board is a two-ended message board for the night: stage management on a phone in the
wings, front of house on the tonight screen. Most of what crosses it is one tap: a milestone
("House open", "Curtain up") or a preset call. This screen is where those buttons are written. It
is at **Manage, Tonight, Backstage board**. Seeing the configuration needs the `board.read`
permission and changing it needs `board.write`; the Front of house manager role holds both.

::callout{icon="i-lucide-info" color="info"}
**Nothing already on the board moves.** A message snapshots its wording when it is sent, so editing
or retiring a type or a preset changes nothing already posted tonight or on any earlier night.
::

Tonight's join code, the reset that kicks every device, and the board itself are not here: they
belong to the night and live on the tonight screen. See
[The backstage board](/docs/show-night/backstage-board).

## Milestone types

A milestone is a structured event with a time and a poster: it feeds the night report's timeline
as well as the board. The set is yours to define; a typical run is clearance, house open, curtain
up, interval, restart and end.

![The backstage board setup with the milestone types (1), Add a milestone type (2), the presets (3) and Add a preset (4)](/images/docs/rota/backstage.png)

1. **Milestone types** are listed in order, with **Edit** and **Retire** beside each. A retired
   type is marked and can be reinstated.
2. **Add a milestone type** asks for a **label** and an **order** (lowest first).
3. **Presets** are listed with their button label and the message underneath.
4. **Add a preset** asks for the **button label** (what the one-tap button says), the **message**
   (what is actually sent) and an **order**.

## Editing and retiring

**Edit** changes the label, message or order for everything sent from now on. **Retire** takes the
button off both ends of the board from the next message; **Reinstate** puts it back. Neither is a
deletion, because posted messages still point at what they were sent as.

## If something goes wrong

- **Save it stays disabled**: the label is empty, or for a preset the message is. Both are required.
- **"No such milestone type"** or **"No such preset"**: it was removed since the page loaded. Reload.

## What happens next

Every change is audited: `backstage-milestone-type.created`, `.updated`, `.retired` and
`.reinstated`, and the same four for `backstage-preset`. The next message sent from either end of
the board picks up the new set.
