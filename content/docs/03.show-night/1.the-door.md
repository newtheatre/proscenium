The door is where a booking becomes a person in a seat. It opens from the hub's **Scan ticket**
tile, or **Admit pass holder** for pass mode, to whoever holds tonight's door shift, and to the
Front of house manager without one. It is door mode and nothing else: no prices, no email
addresses, no booking history. Admit, or send them to the bar.

::callout{icon="i-lucide-info" color="info"}
**The door never sells.** An unpaid booking and a walk-up both go to
[the till](/docs/show-night/the-till), which takes the money and marks the booking paid; the
customer walks back to a green scan. Changes to a booking stay on
[the desk](/docs/box-office/the-desk).
::

## Scanning a ticket

![The door with the performance picker (1), the camera or the reference field (2), the Challenge 25 button (3) and the back arrow (4)](/images/docs/show-night/door.png)

1. **Performance** shows only when the venue runs more than one tonight. It starts on the house
   whose doors are open now; check it on a matinee day, because a ticket for the other
   performance is refused as the wrong one.
2. **The camera** opens by default and stays open. Hold the code inside the gold frame; a torch
   button appears on phones that have one. Where there is no camera, or the browser refuses it,
   the screen says which and shows the **Ticket or pass reference** field instead. Type the
   reference (six characters, like `K7M4PQ`) and press **Check** or :kbd{value="Enter"}. A
   hardware scanner plugged in as a keyboard types the whole URL out of a QR, and that is
   accepted too.
3. **Challenge 25** opens [the register](/docs/show-night/age-checks) without leaving the door.
4. **The back arrow** returns to the hub.

The verdict is big enough to read at arm's length in the dark. With the camera open it sits over
the live view rather than replacing it, so the next person is scanned without touching anything:

- **PAID: Paid, admit.** The booking is marked admitted, with the booker's first name and the
  party size underneath.
- **UNPAID: Send to the bar to pay.** The booking is real but nobody has taken its money. The bar
  collects it and the door then reads PAID.
- **REFUSED**, with the reason named in the line beneath.

The phone buzzes as well as showing the card: once for PAID, twice for UNPAID, one long buzz for
REFUSED, and nothing where the browser cannot buzz at all.

Over the camera, the card clears itself after about three and a half seconds, or sooner when the
next code is read, or on a tap. A REFUSED card and a **NO ANSWER** card hold for eight seconds,
because somebody has to read the reason out. In the typed field the card stays until the next
reference is checked, and the field never moves, so two people in a row are two lookups and no
taps in between. **Type a reference** switches to the field, **Use the camera** switches back.
The camera stops whenever the screen is left or hidden, so a phone in a pocket is not filming.

## Admitting a pass holder

Pass mode opens from the hub's **Admit pass holder** tile, or by itself when the camera reads a
pass QR: a pass is never admitted blind, because the volunteer should read what it covers before
pressing anything.

![Pass mode with the search field (1) and the performance picker (2)](/images/docs/show-night/door-pass-mode.png)

1. **Find the holder** by any part of their name, or by the reference printed on the pass. Two
   characters start the search.
2. **Performance**, as for a ticket.

The hint under the heading carries the standing rule: a refused pass goes to the bar, never to an
argument at the door.

Each card shows the holder, whether the pass is **Active**, what it covers (a fellowship covers
every in-house show), tonight's state (**Not yet redeemed**, **Redeemed, not yet in**, **Already
admitted tonight**) and when it was last used. Where the pass would be refused, the card says so
instead of offering the button. Otherwise press **Admit one**: a pass admits its holder and
nobody else, and creates tonight's £0 pass-admission ticket for the seat.

## If something goes wrong

- **"Wrong performance: This ticket is for …"**: a live booking for a different performance.
  Check the picker at the top; if the ticket really is for another night, send them to the desk.
- **"Admitted: Already checked in at the door."**: this reference has been through already.
- **"Lapsed: This hold was released."**: an unpaid booking that reached its release time. The
  bar can sell them a walk-up if there is room.
- **"Cancelled"** or **"Exchanged for …"**: the booking no longer stands, or was swapped for
  another performance; the line names which.
- **"NOT OURS: That code is not one of ours"**: the camera read something that is neither a
  booking, a pass nor a reference. Try the typed field.
- **"NOT FOUND: That reference is not recognised."**: no booking and no pass carries it. Ask
  them to read it out again; the alphabet has no `0`, `1`, `I` or `O`.
- **"This pass was already admitted tonight, at …"**, **"This pass has expired."**, **"This
  pass does not cover this show."**, **"This pass is not active."**: send them to the bar.
- **"This performance no longer has room for that admission"**: the house is full, so a pass not
  yet redeemed for tonight cannot take a seat. Send them to the bar.
- **"No camera. Type the reference."**, **"Camera not allowed. Type the reference."** and
  **"Camera did not start. Type the reference."**: the typed field is already showing. Allow the
  camera in the browser's site settings to scan next time.
- **"NO ANSWER: The connection dropped, so nothing was checked. Try again."**: the phone could not
  reach the theatre at all, so this is not a verdict on the ticket. Wait a moment and scan it
  again; if the foyer signal is gone, the bar can check the reference on the laptop.

## What happens next

An admission sets the booking's status to admitted, which is what the hub's **collected** figure
and the glance's **to come** count. A pass admission writes a £0 ticket against tonight's
performance in the same moment. Nothing about the person leaves this screen: the first name and
party size are the whole of what door mode may show.
